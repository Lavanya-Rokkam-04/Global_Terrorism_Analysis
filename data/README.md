# Dataset

The analysis uses the Global Terrorism Database (GTD), which contains information on terrorist incidents around the world.

The original dataset is not included in this repository because of its large file size.

The dataset was used locally for analysis and was loaded into Python/Jupyter Notebook using Pandas.

## Data Source

Global Terrorism Database (GTD)

The dataset covers terrorist incidents recorded from 1970 to 2017.

## Note

The dataset is used for educational and analytical purposes. The analysis in this project is based on the available records and does not represent the views of the dataset provider.
